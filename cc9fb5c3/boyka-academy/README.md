# BOYKA SPORTS ACADEMY

Project structure for the Boyka Sports Academy platform for Coach Salem Diab.

## Structure

The project intentionally follows the requested file and folder structure.

## Frontend

```bash
cd frontend
npm install
npm run dev
```

## Backend

The backend requires Node.js and the Express/CORS packages:

```bash
cd backend
npm install express cors
node server.js
```

Copy `.env.example` to `.env` and configure the environment variables before adding the production database/authentication implementation.

## Assets

Place Coach Salem Diab photos in:

`frontend/src/assets/images/coach/`

Academy photos:

`frontend/src/assets/images/academy/`

Training photos:

`frontend/src/assets/images/training/`

Program covers:

`frontend/src/assets/images/programs/`
